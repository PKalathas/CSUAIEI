# HW2: Linked List Implementation

## Rubric
| Criteria                | Points | Description                                          |
|-------------------------|--------|------------------------------------------------------|
| Implementation Correctness | 35  | Do all operations (insert, delete, search) work?     |
| Edge Case Handling      | 25     | Handles empty list, single node, duplicates properly |
| Code Structure          | 20     | Clean class design, proper use of Node/LinkedList    |
| Time Complexity         | 20     | Operations meet expected O(n) or better complexity   |

## Grading Guidance
- This is a data structures assignment. Students must implement from scratch.
- Using Python's built-in list or collections.deque is NOT acceptable and should be heavily penalized.
- Partial credit for methods that work on basic cases but fail edge cases.
- Value clear variable naming and docstrings but don't over-penalize style issues.
- Students should demonstrate understanding of pointer manipulation concepts.
